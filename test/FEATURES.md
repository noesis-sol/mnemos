# Features and their tests

mnemos is a read-only MCP server (TypeScript, Node >=18, npm) that reads Chrome's `Bookmarks`
JSON file and answers five MCP tools over stdio. `src/lib.ts` holds all the logic,
`src/index.ts` is the MCP wiring, `src/icon.ts` is generated by `scripts/build-icons.mjs` from
`assets/`. Tests use Node's built-in runner (`node:test`) against the compiled `dist/` and the
synthetic fixture `test/fixtures/bookmarks.json`, injected through `CHROME_BOOKMARKS_PATH`.

## Suites

| Suite | Runner | Command | What it runs |
|-------|--------|---------|--------------|
| dependencies | `scripts/check-fast.sh` | `npm ci --ignore-scripts` | only when `node_modules` is missing or older than `package-lock.json` |
| build | `scripts/check-fast.sh` | `npm run build` | `tsc`, type-checks `src/` |
| unit tests | `scripts/check-fast.sh` | `npm test` | builds, then `node --test test/lib.test.js test/tools.test.js test/server.test.js` (66 tests, ~0.5s) |
| package dry run | `scripts/check-full.sh` | `npm pack --dry-run` | lists the tarball (runs `prepare`, so builds again); asserts nothing about its contents |

`npm test` names its test files one by one in `package.json`, so a new test file is not run
until it is added there (mnemos-2gg.3 switches it to discovery).

Runner times on macOS, Node 24, three runs each with `node_modules` installed:

- `scripts/check-fast.sh`: 3s–9s (about 4s warm; the first run after a build cache miss is slowest)
- `scripts/check-full.sh`: 3s–9s (about 4s warm; it runs check-fast first)

CI (`.github/workflows/ci.yml`) runs `npm ci`, `npm test` and `npm pack --dry-run` on
ubuntu, macOS and Windows with Node 18 and 22.

## MCP server start and handshake

- **Reached by**: `npx -y mnemos-mcp` or `node dist/index.js` (the `bin` in `package.json`); an
  MCP client connects over stdio and sends `initialize`, then `tools/list`.
- **Tests**: `test/server.test.js` (e2e: spawns `dist/index.js` with `process.execPath` and drives
  it with the SDK's `Client`): the five tools are listed with descriptions and object input
  schemas; a tool call round-trips; a missing bookmarks file comes back as `isError`.
- **Untested**: the `serverInfo` the server reports (name `mnemos`, version read from
  `package.json`, the six icons); the `instructions` string; the `tools` capability. The bin is
  never run through its shebang: the e2e test runs it with `node`.
- **Tickets**: mnemos-2gg.4 (serverInfo, instructions, icons); mnemos-2gg.12 (the bin through its shebang)

## search_bookmarks

- **Reached by**: tool `search_bookmarks(query, folder?, limit?)`; `lib.searchBookmarks`.
- **Tests**: `test/tools.test.js` (unit against the fixture): AND-matching across title, URL and
  folder path; matching through the folder path; Greek query; empty query rejected; word-start
  matching (`ai` misses Gmail and Painting, prefixes match); `total_matches` before truncation;
  folder filter with word-boundary segments; unmatched folder filter note; blank folder filter
  ignored; nodes missing `type`; 5,000-level nesting. `test/lib.test.js` (unit):
  `queryMatches` word starts, Unicode. `test/server.test.js` (e2e): one call by query, one with
  `limit: 1`.
- **Untested**: the note when nothing matches and no folder filter is given; `limit: 0` and a
  negative limit (empty list, true `total_matches`); the default limit of 100 and the cap of 200
  on a file with more than 200 matches; regex special characters in a query word (`c++`,
  `(2024)`); results coming back in document order; the `folder` argument over the wire.
- **Tickets**: mnemos-2gg.7; mnemos-2gg.11 (the `folder` argument over the wire)

## list_folders

- **Reached by**: tool `list_folders()`; `lib.listFolders`.
- **Tests**: `test/tools.test.js` (unit): direct counts and the ` › ` separator; empty folders and
  folders holding only subfolders are listed with `subtree_bookmarks`; non-folder values in
  `roots` are skipped; `total_bookmarks` counts each bookmark once; a brand-new empty profile
  reports zero.
- **Untested**: folders sorted by name; a root key other than `bookmark_bar`, `other` or `synced`
  labelled with its key; a folder with no `name`; two sibling folders with the same name merging
  into one row; a successful call over the wire (only the error path is driven through MCP).
- **Tickets**: mnemos-2gg.8; mnemos-2gg.11 (a successful call over the wire)

## list_folder_contents

- **Reached by**: tool `list_folder_contents(folder, limit?)`; `lib.listFolderContents`.
- **Tests**: `test/tools.test.js` (unit): `ai` does not leak Painting; Greek folder; slash-named
  folder; empty name rejected; subfolders included (via the Research count). `test/lib.test.js`
  (unit): `folderMatches` case, ancestors, Unicode, `/` in names, regex characters, the literal
  `A › B` folder. `test/server.test.js` (e2e): `limit: 1` on `Bookmarks Bar` reports
  `total_matches`.
- **Untested**: the `No folder matches` note; `limit: 0`, the default limit of 100 and the cap of
  200 in `lib`; matching a root label (`Other Bookmarks`, `Mobile Bookmarks`).
- **Tickets**: mnemos-2gg.8

## recent_bookmarks

- **Reached by**: tool `recent_bookmarks(limit?)`; `lib.recentBookmarks`.
- **Tests**: `test/tools.test.js` (unit): corrupt and plausible-future timestamps sort last with
  `added: null`; `total_matches` with truncation. `test/lib.test.js` (unit): `chromeTimeToIso`
  dates, out-of-range, zero/negative/garbage, the clock-skew allowance, pre-1970 dates.
  `test/server.test.js` (e2e): `limit: 1`; a non-integer limit rejected by zod.
- **Untested**: a bookmark with no `date_added` sorting last with `added: null`; the order of
  bookmarks sharing a timestamp; the default limit of 100 and the cap of 200; dates rendered in
  the machine's local timezone (a timestamp near midnight UTC under a non-UTC `TZ`).
- **Tickets**: mnemos-2gg.9

## top_domains

- **Reached by**: tool `top_domains(limit?)`; `lib.topDomains`.
- **Tests**: `test/tools.test.js` (unit): `chrome://` and `javascript:` excluded; `www.` stripped
  and counted with the bare host; IDN rendered as Unicode; `total_matches` with truncation.
  `test/server.test.js` (e2e): `limit: 1`.
- **Untested**: domains ordered by count, highest first; the default limit of 25 and the cap of
  100; `file://` and unparseable URLs skipped; `http:` counted alongside `https:`; subdomains
  kept apart (`docs.anthropic.com` is not `anthropic.com`).
- **Tickets**: mnemos-2gg.10

## Configuration and profile resolution

- **Reached by**: environment variables `CHROME_PROFILE` and `CHROME_BOOKMARKS_PATH`; the platform
  default Chrome directory (`HOME`, `LOCALAPPDATA`, `XDG_CONFIG_HOME`); `lib.chromeBase`,
  `lib.bookmarksPath`, `lib.loadRoots`.
- **Tests**: `test/lib.test.js` (unit): `chromeBase` per platform, `LOCALAPPDATA` and
  `XDG_CONFIG_HOME` honoured, empty variables treated as unset; `bookmarksPath` override and empty
  `CHROME_PROFILE`. `test/tools.test.js` (unit): missing file, malformed JSON and a non-Chrome
  JSON file all give friendly errors.
- **Untested**: `CHROME_PROFILE` actually selecting `<chrome dir>/<profile>/Bookmarks` when the
  file is read; the missing-file error listing the profiles that do have a `Bookmarks` file,
  sorted, or `none` when the Chrome directory is missing; an empty `CHROME_BOOKMARKS_PATH`
  falling back to the profile.
- **Tickets**: mnemos-2gg.6

## Tool errors over MCP

- **Reached by**: any tool call; `safely()` in `src/index.ts` turns a thrown error into an
  `isError` result, and zod validates arguments.
- **Tests**: `test/server.test.js` (e2e): a missing bookmarks file gives `isError` with the
  friendly message; `limit: 2.5` is rejected.
- **Untested**: a missing required argument (`query`, `folder`) and a wrong type (`query: 5`)
  rejected as `isError`; an empty query answered as a normal result carrying `error`, not
  `isError`; a malformed or non-Chrome bookmarks file surfacing as `isError` with its message;
  calling an unknown tool name.
- **Tickets**: mnemos-2gg.11

## Icons

- **Reached by**: the `icons` in `serverInfo` on `initialize`; `src/icon.ts`, generated by
  `node scripts/build-icons.mjs` from `assets/*.svg` and `assets/*.png`.
- **Tests**: none.
- **Untested**: each icon's data URI decoding to the bytes of its asset file, with the right
  `mimeType`, `sizes` and `theme`; one light and one dark variant per format and size; the
  committed `src/icon.ts` matching what `scripts/build-icons.mjs` would generate from `assets/`.
- **Tickets**: mnemos-2gg.5

## Published package

- **Reached by**: `npm publish` / `npx -y mnemos-mcp`; `files` and `bin` in `package.json`.
- **Tests**: `scripts/check-full.sh` runs `npm pack --dry-run`, which only lists the contents.
- **Untested**: the tarball containing `dist/index.js`, `dist/lib.js`, `dist/icon.js` and
  `package.json`, and no `src/` or `test/`; the `bin` target existing in the tarball and starting
  with `#!/usr/bin/env node`; the unpacked package starting through its bin and answering an MCP
  handshake.
- **Tickets**: mnemos-2gg.12
